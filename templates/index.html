TOKEN ANALYSIS

Visible NLP Processing Pipeline

Every step of token processing is computed in real time without black-box models.

1

Unicode Normalization

Normalizes text into canonical Unicode NFC form (NFC).

2

Whitespace Normalization

Collapses repeated spaces, tabs, and newlines into single spaces.

3

Punctuation Handling

Separates and cleans standard and Indic punctuation (।, ॥, ., ?, etc.).

4

Tokenization

Splits preprocessed text into distinct Gujarati word tokens.

5

Stopword Handling

Stopword Removal: DISABLED

Stopwords are deliberately retained. In N-gram language modeling, common grammatical particles (હું, છે, અને, માં) provide essential transition context between adjacent words.

6

Vocabulary Verification

Each token is verified against the training corpus vocabulary.

# Token In Vocabulary Status
7

Candidate Generation & Levenshtein Distance

For misspelled words, candidates are generated from vocabulary with edit distance ≤ 1, ≤ 2, or ≤ 3.

8

N-Gram Context & Final Ranking

Candidates are evaluated using Trigram, Bigram, and Unigram transition probabilities from the statistical model. Lower edit distance is prioritized, then contextual probability.
